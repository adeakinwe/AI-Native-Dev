# AI Portfolio Tracker

## Project
A web application for tracking stocks, ETFs, bonds, mutual funds and crypto.

## Stack
Backend: ASP.NET Core 8
Frontend: Angular 17
Database: PostgreSQL
Authentication: JWT

## Rules
- Write tests for new functionality
- Never break existing tests
- Prefer small commits
- Ask before large refactors
- Follow clean architecture

## Agent Roles

### PM
Defines requirements and acceptance criteria.

### Developer
Implements requirements and writes tests.

### QA
Reviews implementation and validates requirements.
